# Worked example

A real run, copied out of `prospects.db` unedited. Nothing here was written by
hand; every company, signal and draft came from the agent choosing its own tools.

```
$ python run.py "early-stage Indian SaaS startups that are hiring AI engineers" \
      --target 2 --min-score 55
```

## What it cost

```
iterations 20    tokens 160,441 in / 4,549 out
cost $0.00 (free tier; would list at $0.0595)
cost per qualified prospect $0.0000
```

Run on Gemini's free tier. On paid Claude the same run lists at a few cents.

## What it did

Twenty iterations, eight searches, five page fetches. The searches narrowed on
their own, from a broad description to named companies:

```
search_companies    Indian AI SaaS startups hiring "AI engineer" or "Machine Learning"
search_companies    YC India startups hiring "AI engineer" OR "Machine learning"
search_companies    "Peakflo" careers "AI" OR "Machine Learning" OR "ML"
fetch_company_page  https://peakflo.co/about-us
extract_signals     Peakflo
score_fit           Peakflo
save_prospect       https://peakflo.co/
search_companies    "YC" Indian AI startups hiring OR careers OR jobs
search_companies    "SaaS Go Live in Days, not Months" Y Combinator
search_companies    "Lab0" company website Y Combinator
fetch_company_page  https://lab0.ai/yc          <- dead path
fetch_company_page  https://lab0.ai/            <- recovered, still thin, dropped
search_companies    "Portkey.ai" OR "Portkey AI" careers "AI Engineer"
search_companies    "TrueFoundry" careers OR jobs "AI" OR "Engineer"
fetch_company_page  https://www.truefoundry.com/careers
extract_signals     TrueFoundry
score_fit           TrueFoundry
save_prospect       https://www.truefoundry.com/careers
```

Two things in that trace are worth more than the output. The Lab0 detour is the
agent hitting a dead URL, retrying the root domain, finding nothing worth
scoring, and moving on without being told to. And Lab0 never became a prospect,
which is the point: a tool that returns everything it looked at is a search
engine, not a filter.

## Model switching

Gemini's free tier returned 503 repeatedly. The run finished anyway:

```
note: gemini-3.5-flash was unavailable (ClientError); switched to gemini-3.7-flash
note: gemini-3.7-flash was unavailable (ClientError); switched to gemini-3.6-flash
note: gemini-3.6-flash was unavailable (ServerError); switched to gemini-flash-latest
note: gemini-flash-latest was unavailable (ServerError); switched to gemini-3.6-flash
note: gemini-3.6-flash was unavailable (ClientError); switched to gemini-3.7-flash
note: gemini-3.7-flash was unavailable (ClientError); switched to gemini-3.6-flash
```

Six switches in one run. Without the fallback chain this would have been an
apparent hang, because the SDK retries the same overloaded model in silence.

## Prospect 1 — TrueFoundry, fit 95

Signals the agent extracted from the careers page:

> Early-stage Indian AI/LLMOps SaaS startup founded by IIT Kharagpur alumni,
> offices in Bengaluru and San Jose. Builds AI infrastructure (AI Gateway, MCP
> Gateway, LLMOps). Actively hiring AI/ML engineers, including Senior AI/ML
> Engineer for the LLM and Agent Stack.

Draft, passed review on the first attempt:

> **Subject:** Hiring AI engineers at TrueFoundry
>
> Saw you are currently hiring a Senior AI/ML Engineer in Bengaluru for your LLM
> and agent stack.
>
> Finding candidates with hands-on experience in agent frameworks and LLMOps is
> difficult right now. We help early-stage Indian startups source and screen
> pre-vetted AI engineers to fill open roles faster.
>
> Would you be open to reviewing two or three candidate profiles for this
> position this week?

Critic verdict, `pass`:

> The draft directly references TrueFoundry's specific open role for a Senior
> AI/ML Engineer on their LLM and agent stack in Bengaluru, stays strictly
> within word limits, and asks a single clear question.
